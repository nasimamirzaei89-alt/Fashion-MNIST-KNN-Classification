# Fashion-MNIST Image Classification Using KNN

## Project Overview

This project focuses on image classification using the Fashion-MNIST dataset and the K-Nearest Neighbors (KNN) algorithm.

The main goal is to classify images of clothing items based on their pixel values and evaluate the performance of different KNN configurations.

## Dataset Description

Fashion-MNIST is a dataset containing 70,000 grayscale images of clothing items. Each image is 28 × 28 pixels and belongs to one of 10 different classes, including T-shirts, trousers, dresses, coats, sandals, sneakers, bags, and boots.

Each image is represented by numerical pixel values and is used as input for the classification model.

## Project Workflow

The project is organized into five Jupyter notebooks:

- **Step 1 – Data Exploration:** Loading and exploring the dataset, visualizing sample images, examining class distributions, and using t-SNE to visualize class separability.
- **Step 2 – Data Preprocessing:** Splitting the dataset into training, validation, and testing sets, applying Min-Max scaling, and reducing dimensionality using PCA.
- **Step 3 – KNN Implementation:** Implementing the KNN algorithm from scratch using NumPy, including distance calculation and distance-weighted voting.
- **Step 4 – Hyperparameter Tuning:** Experimenting with different hyperparameters, including the number of neighbors, PCA variance ratio, scaling method, and distance metric.
- **Step 5 – Final Evaluation:** Evaluating the selected model on the test set and reporting classification metrics and ROC curves.

## Best Model Configuration

- Algorithm: K-Nearest Neighbors (KNN)
- PCA explained variance: 95%
- Number of PCA components: 187
- Distance metric: Manhattan
- Number of neighbors (K): 5
- Weight function: Distance

## Results

- Validation Accuracy: 86.89%
- Test Accuracy: 86.88%
- Macro ROC-AUC: 97.35%

## Project Files

The repository contains five Jupyter notebooks covering the complete workflow, along with supporting NumPy arrays for the preprocessed validation and testing data and their corresponding labels.

## Note on Dataset Files

The `train_preprocessed.npy` file was not included in this repository because its file size exceeded GitHub's upload limit.

This file contains the preprocessed training features of 49,000 Fashion-MNIST images. In the Step 2 preprocessing workflow, the images are normalized using Min-Max scaling and transformed using PCA. The resulting feature array used in Step 3 contains 84 features per image.

The file can be regenerated by running the corresponding preprocessing steps in Step 2 before executing notebooks that depend on it.
