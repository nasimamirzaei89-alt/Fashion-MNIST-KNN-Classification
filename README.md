# Fashion-MNIST Classification Using KNN

This project focuses on classifying Fashion-MNIST images using the K-Nearest Neighbors (KNN) algorithm.

## Project Overview

The project includes:
- Fashion-MNIST data exploration and visualization
- Data preprocessing and dimensionality reduction using PCA
- KNN implementation and classification
- Hyperparameter tuning
- Model evaluation using accuracy, precision, recall, F1-score, and ROC-AUC

## Best Model

- Algorithm: K-Nearest Neighbors (KNN)
- PCA explained variance: 95%
- Number of components: 187
- Distance metric: Manhattan
- Number of neighbors: 5
- Weight function: Distance

## Results

- Validation Accuracy: 86.89%
- Test Accuracy: 86.88%
- Macro ROC-AUC: 97.35%

## Project Files

The repository contains five Jupyter notebooks covering different stages of the project, along with supporting dataset files.
